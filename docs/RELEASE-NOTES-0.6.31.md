# NextGlance 0.6.31

23 November 2026 · Windows, Android and Nextcloud

- Timeline shows completed tasks and cards from the last 14 days by default. Change the limit in **Timeline → Filters → Completed items** independently of Board.
- Linked tasks under **Waits for** and **Needed by** show their unified status and color for the current Space.
- Removing a shared-file attachment uses Deck's file-specific endpoint to unlink the attachment while keeping the original file or note.

Build 33 uses Windows file version `0.6.31.33` and Android versionCode `33`. The Windows shortcut target is `win/release/NextGlance-Latest.exe`.
