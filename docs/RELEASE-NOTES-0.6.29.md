# NextGlance 0.6.29

23 November 2026 · Windows, Android and the Nextcloud app

- The Board uses the Timeline’s icons for tasks and Deck cards. Standalone tasks fit the title, source list and due date into two lines. Hover or focus a task for its additional details. On touch screens, select the task for details or use its existing Move control.
- Calendar deletion verifies the original DAV revision when an unchanged event’s GET response carries a different representation ETag. A genuine revision or content change still prompts review. Deleting a linked event preserves its Deck card and saved relationship.

Build 31 uses file version `0.6.29.31` on Windows and versionCode `31` on Android. Use `win/release/NextGlance-Latest.exe` as the permanent Windows shortcut target.
