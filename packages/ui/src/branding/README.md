# Approved icon assets

**Approved: 2026-11-17. Decision: BRAND-01.** These are the canonical NextGlance application icons.

- `nextglance-master.svg`: editable source with the chosen overlap and negative space.
- `nextglance-icon.svg` / `.png`: default blue-and-white launcher badge.
- `nextglance-mark.svg`, `nextglance-mark-dark.svg`, `nextglance-mark-current.svg`: compact monochrome variants for host/in-app surfaces.
- `nextglance-adaptive-foreground.svg` / `.png`: Android adaptive/themed foreground with safe padding.
- `nextglance-gradient-dark.svg`, `nextglance-gradient-white.svg`: approved alternate badge treatments.
- `manifest.json`: approval metadata, coordinate frames and content hashes.

Delivery SVGs use a flattened path with true transparent cutouts, without masks, external references or embedded bitmaps. The editable master retains its original vector layers. Follow [the branding guide](../../../../docs/BRANDING.md) when deriving platform assets. Do not substitute earlier drafts or change application/account/storage identifiers when updating visible branding.
